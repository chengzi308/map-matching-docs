# 工作计划

## 8.8 ~ 8.14（工作计划）

### 1. 匹配错误路段分级排查

#### 排查顺序

| 档位 | 轨迹范围 | 轨迹数 |
|------|----------|--------|
| 第一档 | 全部≤5m | 564 |
| 第二档 | 最差5-10m | 6,585 |
| 第三档 | 最差10-20m | 15,019 |
| 第四档 | 最差20-30m | 6,148 |
| 第五档 | 最差≥30m | 18,513 |

#### 排查路线一：GPS轨迹本身的问题

| 问题 | 应对方法 |
|------|----------|
| 隧道/高架信号中断 | 切断轨迹 |
| 长时间停车 | 切断轨迹 |
| GPS漂移点 | 删除漂移点 |
| 冷启动延迟 | 删除前3-5个点 |
| 静止漂移 | 合并为质心点 |

#### 排查路线二：FMM匹配本身的问题

| 问题 | 应对方法 |
|------|----------|
| 对向车道误配 | 检查方向夹角 |
| 平行路混淆 | 缩小搜索半径 |
| 路口歧义 | 增加轨迹点权重 |
| 跨线跳变 | 合并连续小段 |
| 系统性困难场景 | 标记为系统性困难路段 |

#### 排查路线三：OSM离线地图的问题

| 问题 | 应对方法 |
|------|----------|
| 悬空节点 | 合并节点 |
| 路口未建模 | 新增连接边 |
| 路段几何偏移 | 修正坐标 |
| 路段缺失 | 聚类拟合新路段 |
| OSM数据过时 | 修正元数据 |
